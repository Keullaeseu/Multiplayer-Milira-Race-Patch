# Multiplayer Milira Race Patch

A RimWorld Multiplayer compatibility patch for [Milira Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3256974620).

This mod is designed to improve multiplayer synchronization when playing with the [Milira Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3256974620) mod and RimWorld Multiplayer.

## Features

- Adds multiplayer compatibility for [Milira Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3256974620).

## Requirements

- RimWorld
- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)
- RimWorld Multiplayer
  - [GitHub version](https://github.com/rwmt/Multiplayer) or [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745) version
- [Milira Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3256974620)
- [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276) (Milira Race dependency)
- [Multiplayer Ancot Library Patch](https://github.com/Keullaeseu/Multiplayer-Ancot-Library-Patch/releases/latest)
  — required: covers Ancot Library weapon systems used by Milira (e.g. Plasma Pistol
  rapid/scatter fire-mode switch, mech auto-fight). Without it, switching fire modes desyncs.
- [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762) (Milira Race dependency)
- [Multiplayer Humanoid Alien Races Patch](https://github.com/Keullaeseu/Multiplayer-Humanoid-Alien-Races-Patch/releases/latest)
  — required: covers the styling station and alien-comp appearance sync for HAR races including Milira.

The host and every connected player must use compatible versions of all required mods.

## Installation

### Steam Workshop

Subscribe to the required mods and add them to your RimWorld mod list in the following order:

1. Harmony
2. Core
3. Royalty, Ideology, Biotech, and Anomaly, if applicable
4. RimWorld Multiplayer
5. [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276)
6. [Multiplayer Ancot Library Patch](https://github.com/Keullaeseu/Multiplayer-Ancot-Library-Patch/releases/latest)
7. [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762)
8. [Multiplayer Humanoid Alien Races Patch](https://github.com/Keullaeseu/Multiplayer-Humanoid-Alien-Races-Patch/releases/latest)
9. [Milira Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3256974620)
10. [Multiplayer Milira Race Patch](https://github.com/Keullaeseu/Multiplayer-Milira-Race-Patch/releases/latest)

The patch should load after RimWorld Multiplayer, [Milira Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3256974620), and both companion patches listed above.

### Manual Installation

1. Download the latest release from the [**Releases**](https://github.com/Keullaeseu/Multiplayer-Milira-Race-Patch/releases/latest) section.
2. Extract the mod folder into your RimWorld `Mods` directory.
3. Enable the required mods in RimWorld.
4. Use the recommended load order listed above.
5. Make sure every multiplayer player has the same mod list, configuration, and load order.

## Multiplayer Usage

All players should have the following mods installed and enabled:

- RimWorld Multiplayer
- [Milira Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3256974620)
- [Multiplayer Milira Race Patch](https://github.com/Keullaeseu/Multiplayer-Milira-Race-Patch/releases/latest)
- [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276)
- [Multiplayer Ancot Library Patch](https://github.com/Keullaeseu/Multiplayer-Ancot-Library-Patch/releases/latest)
- [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762)
- [Multiplayer Humanoid Alien Races Patch](https://github.com/Keullaeseu/Multiplayer-Humanoid-Alien-Races-Patch/releases/latest)
- All other required Milira Race dependencies

The host and all connected clients should use the same:

- RimWorld version
- RimWorld Multiplayer version
- Milira Race version
- Multiplayer Milira Race Patch version
- Multiplayer Ancot Library Patch version
- Multiplayer Humanoid Alien Races Patch version
- Mod configuration
- Mod load order

Do not add, remove, update, or reorder mods while players are connected to the same multiplayer session.

## Compatibility

This patch is intended to provide multiplayer compatibility for [Milira Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3256974620)
itself (fly abilities, hair customization, gizmos, job orders, incident targeting).
Ancot Library weapon systems and Humanoid Alien Races styling are covered by the
required companion patches listed above, not duplicated here.

It does not replace:

- [RimWorld Multiplayer](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745)
- [Milira Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3256974620)

## Known Limitations

- Compatibility may be affected by future RimWorld updates.
- Compatibility may be affected by future updates to RimWorld Multiplayer or Milira Race.
